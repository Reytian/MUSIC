# MUSIC

Music tools for [Claude Code](https://claude.ai/code): a Guitar Pro MCP server and a tab transcription skill.

## Projects

### [guitar-pro-mcp/](guitar-pro-mcp/)

A Python MCP (Model Context Protocol) server that lets Claude Code create and edit Guitar Pro tab files (.gp5). Supports 7 tools, 13 tunings, and 12 instruments.

### [guitar-tab-transcription/](guitar-tab-transcription/)

A Claude Code skill with guidelines for transcribing guitar/bass tabs from video into Guitar Pro files. Includes 6 core rules and a reference of common mistakes from real transcription sessions.
