# CADENCE-1 for M-VAVE FM-1

CADENCE-1 是一套独立的乐理学习固件，思路取自 Tenuto，并把 FM-1 的真琴键用作主要的作答方式。名字取自和声里的终止式（cadence），也指每天练习的节奏。0.5.0 以前叫 KeyStudy。**HOME** 进入学习，**SEQ** 进入练习。开机显示学习页，默认示例是 **Bm7**。

## 学习

转动 **SELECT** 选择音名、音程、三和弦、七和弦或音阶。转动 **ALGORITHM** 选择类型，转动 **PRESETS** 更换根音。

屏幕显示一组五线谱和对应的琴键。和弦按原位叠写，音程和音阶按演奏顺序排列。按 **PLAY** 试听，和弦也可按 **ARP** 逐音试听，播放到的音符会高亮。

黑键根音按"升降号最少"取名：大三和弦写 Db，小三和弦写 C#，G# 小调不写成 Ab 小调。音程共 13 种，增四度（A4）和减五度（d5）分开。

按 **OCT−** 或 **OCT+** 把琴键和谱面一起移动一个八度，可各移一次。低音谱号下琴键默认低一个八度（F2 到 G4），音符落在谱表内。练习中换八度会开始新一轮。

按 **SEL** 打开八张乐理速查卡，转 **SELECT** 翻页，按 **PLAY** 听例子。按 **GLO** 打开六个计算器：临时升降号、音程、音阶、和弦、罗马数字和声、十二音矩阵。罗马数字带数字低音（V6/5、viiø4/3 等）；用 **K2** 升降级数得到借用和弦，例如 C 大调的 bII 是 Db 大三和弦。

## 练习

按 **SEQ** 回到上次的练习，进度不变；关机重开后也回到上次打开的那项。新机器第一次按 **SEQ** 进入 Keyboard 的音名题。按 **GLO** 打开练习目录，转 **SELECT** 选组，转 **PRESETS** 选练习，按 **EDIT** 打开。再按 **GLO** 不换练习直接返回。

| 组 | 看到或听到的 | 怎么答 | 练习 |
| --- | --- | --- | --- |
| Play Name | 名称 | 弹琴键 | 音名、音程、音阶、和弦、转位 |
| Play Staff | 五线谱 | 照谱弹，八度也要对 | 音符、音程、音阶、和弦、旋律 |
| Play Ear | 声音，起始键亮灯 | 弹回来 | 单音、音程、和弦、旋律 |
| Play Key | 调和级数 | 弹琴键 | 音级、调内和弦、和弦进行 |
| Read Staff | 五线谱 | 在屏幕上选 | 音名、调号、音程、音阶、和弦 |
| Write Staff | 名称 | 写到谱上 | 音符、调号、音程、音阶、和弦 |
| Keyboard | 亮起的琴键 | 在屏幕上选 | 音名、音程、音阶、和弦 |
| Ear Training | 声音 | 在屏幕上选 | 音名、音程、音阶、和弦 |

共 35 项练习。可用 FM-1 自带琴键，也可通过 3.5 mm TRS MIDI IN 或电脑的 USB MIDI 作答。外接键盘如果有音没有松开，按 **HOME** 或 **SEQ** 会把它们放掉。

### 作答

- **弹琴键**。和弦同时按住，任意转位和八度重复都算对；**ARP** 切换到逐音输入（Tap），**REC** 清空。音程和音阶从根音起逐音向上弹，**REC** 重来。转位题要求指定的音在最低。照谱弹的和弦要按谱上写的那几个键，旋律按谱上的顺序逐个弹。和弦进行逐个弹，换和弦前先松手。
- **在屏幕上选**。所有选项排成网格，转 **PRESETS** 移动高亮，按 **EDIT** 提交。音名题用 **ALGORITHM** 选升降号，和弦题用 **ALGORITHM** 选根音。
- **写到谱上**。**SELECT** 选音符位置，**ALGORITHM** 上下移动，**PRESETS** 改升降号，**SEL** 写入，**REC** 擦除。也可以弹琴键录入再修正写法。调号题用 **PRESETS** 增减升降号。

**FX** 看提示，**SAVE** 跳过，**PLAY** 试听。听辨题的 **PLAY** 是重听题目；其他题在答对前按 **PLAY** 算用了提示。弹琴键和屏幕选择的练习里，转 **SELECT** 可换到同组的下一项练习。

提示分两步，第一次按 **FX** 只给线索，不给答案：

- 给出名称的题，线索是它的规则：音程的半音数和字母数，和弦、音阶的公式，调号的升降号顺序，音名在黑键间的位置。
- 读谱和看琴键的题，线索是读法：谱表线和间的口诀、调号、音程的度数、音阶的全音和半音排列、和弦的根音。
- 听辨题把题目换个方向给出：要选名称的，亮出琴键；要弹出来的，给出名称。

再按一次 **FX** 显示答案。

### 反馈

- 答对后自动进入下一题，可在设置里改为按 **EDIT**。
- 答错时错的琴键或音符显示为红色，PLAY 灯闪红。下面这几种答错，屏幕会说明哪里对、哪里错：
  - 和弦识别题，根音和类型只对了一样；
  - 写谱时键对了但字母不对，或字母对了但升降号不对；
  - 读谱时选了同一个键的另一个名字；
  - 音程的度数对了但半音数不对，或半音数对了但度数不对（例如 A4 和 d5）。
- 听辨题答错后，先播放你选的，再播放题目，便于对比。
- 同一题错两次后直接给出答案并播放，次数可在设置里改。答案旁边附上规则，例如 C + m6 写着 "Minor 6th: 8 half steps, 6 letters"，Bb 小调写着 "Like Db major: Bb Eb Ab Db Gb"。
- 弹琴键的题给出答案后，琴键继续接收输入：照着亮起的键弹对一次就进下一题。这一次不计分，也可以按 **EDIT** 直接继续。
- 答错、跳过和看了提示才答对的题，隔三题会再问一次。每题只回问一次，之后留在本轮的复习清单里。
- 第一次遇到一种音程、和弦或音阶时，先展示再考：屏幕显示名称、规则、谱面和琴键，并播放声音，标着 NEW。照着弹一次或按 **EDIT** 后继续，几题之后再正式考它。展示不算本轮的题，限时的一轮里不展示。
- 听辨题在出题时自动播放。

### 一轮

默认每轮 10 题。一轮结束显示首答正确数、平均用时和需要复习的条目。按 **EDIT** 开始新一轮，按 **SEL** 只重练错题。

同一项练习里，所有条目轮过一遍才会重复。每个条目有一个 0 到 5 的熟练度：答得又对又快上升，答错或跳过下降。熟练度低的先出，已经很熟的大约每两轮才出一次。熟练度保存在机器里，关机不丢：每轮结束时保存，一轮当中每分钟保存一次。

设置里可把一轮改成限时 1 到 3 分钟，结束时显示每分钟首答正确数，并记录每项练习的最好成绩。

### 分级

默认按级别出题，每类内容各有一个级别，从第 1 级开始。一轮不少于 5 题且首答正确率达到 90% 时，结果页会提示升级，按 **SAVE** 接受。级别也可在设置里直接改。

| 类别 | 各级内容 |
| --- | --- |
| 音符 | 1 谱表内的自然音；2 加线；3 升降号；4 调号 |
| 音程 | 1 M2 M3 P4 P5 P8；2 加 m2 m3；3 加 m6 M6；4 加 m7 M7；5 加 A4 d5 |
| 和弦 | 1 白键根音的大小三和弦；2 十二个根音；3 加减、增；4 加 sus2、sus4；5 加 maj7、m7、7；6 加 m7b5、dim7、mM7；7 加转位 |
| 音阶 | 1 白键根音的大调；2 十二个根音；3 加自然小调；4 加和声、旋律小调；5 加五声音阶；6 加调式 |
| 调 | 1 C、G、F 大调；2 三个升降号以内；3 加小调，五个以内；4 全部 15 个调号 |

音符第 4 级起，读谱题带调号，谱上不写升降号的音要按调号来读。和弦第 7 级的转位不包括 sus2 和 sus4：它们转位后就是另一个挂留和弦，无法分辨。旋律题（听奏和照谱弹）的长度随音符级别增加；照谱弹的旋律在第 2 级之前只用谱表内的音，在第 4 级之前只用 C 大调。调的级别还决定调内和弦与和弦进行的范围：第 1 级只有 I、IV、V，第 3 级起有七和弦和小调的进行。

## 设置

按 **ENV** 打开设置，转 **SELECT** 选择项目，转 **PRESETS** 调整。按 **SAVE** 应用并保存，再按 **ENV** 放弃修改。改变出题条件会开始新一轮。

- **Staff clef**：高音或低音谱号。
- **Questions per round**：每轮 5 到 30 题。
- **Timed round**：关闭，或限时 1 到 3 分钟。
- **Next question**：答对后自动进题，或按 **EDIT**。
- **Reveal the answer**：错 2 次、错 3 次后给出答案，或从不。
- **Material**：选 **Levels** 按上表分级，下面显示五个级别；选 **Custom** 则自己筛选，下面显示音程、和弦、音阶的类型筛选（用 **PRESETS** 浏览，**SEL** 切换是否纳入）、单音是否只用自然音、和弦是否带转位、读谱是否带调号、是否用加线。
- **Ear interval order**：听辨音程上行、下行或同时。
- **Tone**：**Grand Piano**（Yamaha C5 三角钢琴录音）或 **Pure Tone**，转到这一项时弹琴即可试听。

从 0.4 升级时原有设置会保留。没动过筛选的机器改用分级；动过的保持自选，原来的三全音对应成 A4 和 d5 两项。

## 试听与安装

- **先试听**。在 [FM-1 Emulator](https://joakimeriksson.github.io/fm1-emu/) 选择 **Open .fwsc…**，打开 [cadence-1-0.5.0.fwsc](dist/cadence-1-0.5.0.fwsc)。
- **安装到 FM-1**。固件包适用于 M-VAVE FM-1。刷写前备份目前的固件与数据，可使用 [M-Flasher](https://github.com/jvitkauskas/m-flasher)。在已经运行兼容社区固件的 FM-1 上，可用数据线连接并运行下面的更新程序。它会显示识别到的设备，确认后才开始写入。

```sh
python3 base/tools/fm1_install.py dist/cadence-1-0.5.0.fwsc
```

更新程序需要 `mido` 和 `python-rtmidi`。首次使用原厂固件或其他引导程序的机器，请按现有固件的安装路径操作。设备固件身份为 `FM-1_54000500`。文件校验值见 [SHA256SUMS](dist/SHA256SUMS)。

0.5.0 已在桌面模拟器、fm1-emu 网页模拟器（原样运行这个固件包，模拟 FM-1 的芯片）和一台 FM-1 真机上测过。

## 构建与验证

先安装 Python 3 和 Pillow。真机包另外需要 [JieLi Linux x86‑64 工具链及 AC79 SDK](https://github.com/charlesvestal/fm1-base)，Apple silicon Mac 可用支持 linux/amd64 的 Docker 环境。

```sh
./build.sh --release 0.5.0
./build.sh --host
cc -std=c99 -Wall -Wextra -Werror tests/notation.c -o app/build/host/notation_test
app/build/host/notation_test
for scenario in tests/*.txt; do
  app/build/host/cadence-1_host "$scenario" app/build/host || exit
done
```

工具链在容器里运行，默认镜像是 `debian:bookworm-slim`，可用 `JIELI_DOCKER_IMAGE` 换成本机已有的镜像。编译器在 amd64 模拟下偶尔会崩溃并留下 `core` 文件，重跑即可，`FM1B_JOBS=1` 能减少发生。

桌面测试有 16 个场景，覆盖：

- 全部 35 项练习的入口，四种弹奏判分，屏幕选择和谱面构建；
- 反馈和揭示答案，两步提示与各类题的规则文字，答错的说明；
- 揭示后照弹一次，第一次遇到的内容先展示，回问；
- 一轮的出题与统计，错题重练，升级，各级别的内容，限时；
- 进度、设置和上次练习的保存，以及从 0.4 设置的迁移。

`tests/notation.c` 另校验 1,836 个示范音的记谱音高、等音根音的取名和罗马数字的标记。

测试脚本用以下命令布置场景，见 `app/screen.h` 里的 `app_host_cmd`：

- `ask`、`seed`、`level`、`activity`：指定题目和练习；
- `teach 0`：关掉首次展示；
- `card`、`title`：核对卡片上的文字。

固件镜像约 549 KB，应用槽位 581 KB；其中钢琴采样占 394 KB。

`build.sh` 会取得固定版本的 fm1-base 与 felucca-bsp。可用 `JIELI_TOOLCHAIN`、`AC79_SDK` 和 `PYTHON` 指定安装位置。源代码在 `app/`，生成的固件在 `app/build/`。

CADENCE-1 与所用平台代码采用 MPL-2.0。平台来自 [fm1-base](https://github.com/charlesvestal/fm1-base/tree/3c4a57eea659f942b0c80a99949dddafc094a57b) 和 [felucca-bsp](https://github.com/hugelton/felucca-bsp/tree/41a6e86d921f842243bd01a48111832f7e55b4e2)。固件包所含的 JieLi SDK 组件、Barlow 字体及 Bravura 乐谱符号的许可见 [dist/licenses](dist/licenses)。

谱面符号取自 [Bravura](https://github.com/steinbergmedia/bravura/tree/37b194378b710cc40e406ab6c4b07608bb9548ae)。可用 `python3 tools/rasterize_staff.py Bravura.otf app/staff_glyphs.h` 重建符号位图。

钢琴录音的来源、处理和许可见 [Salamander Grand Piano 音源说明](dist/licenses/Salamander-Attribution.md)。音源已打包在固件中。
